# Ring Ceremony Invitation - Harsh & Chetna

Animated, mobile-first digital invitation (plain HTML/CSS/JS, no build step).

- **Date:** Sunday, 15 November 2026, 10:30 AM onwards (IST)
- **Venue:** The Grand Orchid Banquets & Party Hall, Delhi Road, Hapur - links to Google Maps

## Run locally
Open `index.html` in a browser, or `python3 -m http.server` and visit http://localhost:8000.

## Customise
Edit `EVENT_DATE` at the top of `script.js` to change the date/time and countdown.
